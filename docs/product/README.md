# iOS Boilerplate

iOS Boilerplate is the shared production foundation for new native apps. It exists to remove repeated setup work so a derived app can begin with its product promise, first-value journey, and launch-specific behavior.

## Product Boundary

This is an internal developer product and open-source starter, not a consumer App Store app. The repository owns reusable source, tests, CI, technical runbooks, the product promise, current decision posture, portfolio role, and backlog.

Derived apps copy the starting implementation and become self-contained. They do not depend on the boilerplate repository at runtime.
